## Coverage summary

- **Genres covered:** crossword (+mini/cryptic/variants), word search / hidden-word,
  anagram / word-formation builders, Wordle-like guessing/deduction,
  word-connection/grouping, tile-placement board games, word ladder/transformation,
  typing/speed, narrative/adventure, plus semantic-similarity guessing.
- **Standout formats profiled:** NYT Letter Boxed, Spelling Bee, Strands,
  Connections, Semantle, Absurdle.

## Known gaps

- **Hard popularity metrics** (downloads, DAU/MAU, revenue, demographics) are
  NOT included — the researcher could not reach app-analytics sources
  (Sensor Tower / data.ai / Statista) and estimates were deliberately excluded.
- Monetization and mechanics-trend detail is qualitative; several individual
  title fact sheets beyond the NYT suite remain unsourced.

See each file's own sources section for citations and per-section gap notes.
