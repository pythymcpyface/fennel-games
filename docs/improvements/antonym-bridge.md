# Antonym Bridge — Improvement Notes

Mechanic: chain antonym hops from a start word to its far opposite (HOT→COLD→WARM→COOL).

## Fun
- **Bridge-building animation**: each hop lays a plank across a gap toward the target; the
  bridge visibly extends, and completing it lets a little figure "cross" (playful payoff).
- Antonym flip: the word visibly inverts (rotate/color-swap, fast-02) on each hop.
- Reduced-motion: static plank additions.

## Addiction
- Semantic pathfinding + par → "bridged in fewest hops" efficiency badge; streak.
- Antonym-pair discovery collection; brain-training/education framing.

## Marketability / share
- Share hop-bar ↔️🟩🟩⬛ + start/target teaser ("GIANT → TINY, how few hops?"). The
  opposites framing is intuitive and challenge-friendly.
